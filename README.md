# OpenWithMgt

Windows 右键菜单"用 xxx 打开"项管理工具（针对**文件**的右键菜单）。

基于 C# / WPF / .NET 8，开发者：minichen2000。

## 功能

- 列出系统中所有针对文件的右键菜单项（`HKCU` 与 `HKLM` 下 `Software\Classes\*\shell`），显示名称、键名、命令、图标、来源
- **删除**不再需要的菜单项（带二次确认）
- **添加**新的"用 xxx 打开"菜单项：自定义键名、显示名称、程序路径、参数（默认 `%1`）、图标
- 支持选择添加到 **当前用户 (HKCU)** 或 **所有用户 (HKLM)**

## 系统要求

- Windows 10 / 11（64 位）
- 程序清单声明了 `requireAdministrator`，启动时会请求 UAC 提权，以便管理 HKLM（所有用户）下的菜单项

## 使用方法

1. 以管理员身份运行 `OpenWithMgt.exe`
2. 上方列表展示当前所有文件右键菜单项，点击"刷新"重新读取
3. 选中某行后点击"删除选中项"，确认后删除（不可恢复，请谨慎）
4. 在"添加新项"区域填写：
   - **键名**：注册表中的内部标识（必填，不能含反斜杠）
   - **显示名称**：菜单上显示的文字（留空则使用键名）
   - **程序路径**：要打开文件的程序，可点"浏览…"选择（选择后自动填充键名）
   - **参数**：默认 `%1`，表示被右键点击的文件路径
   - **图标**：可选，图标文件路径
   - **添加到**：当前用户 (HKCU) 或所有用户 (HKLM)
5. 点击"添加"后立即生效，无需重启
